# Project memory (Claude Code)

Design/development notes captured while building the scribbler-simulator with Claude Code — board layout, robot sizing/aspect ratio, random-board generation, competition buttons, test-coverage gaps, and SDLC-phase notes. Public-safe: no secrets, credentials, or personal data (internal session IDs stripped).

## Use on a new machine

Copy these `*.md` files (except this README) into your Claude Code project memory dir so the assistant recalls past design decisions:
`~/.claude/projects/C--code-scribbler-simulator/memory/`
(Clone the repo to a path whose slug matches `C--code-scribbler-simulator` so Claude Code associates them automatically.)
